# chytry-kosik-public

Chytrý košík - public docs (Privacy Policy, Terms of Service, landing page).

🌐 **Live:** [chytrykosikapp.cz](https://chytrykosikapp.cz)

## Obsah

| Soubor | URL po deploy | Popis |
|---|---|---|
| `index.html` | `/` | Landing page Chytrý košík |
| `privacy.html` | `/privacy` | Zásady ochrany osobních údajů (GDPR-compliant, v1.1 Firebase) |
| `terms.html` | `/terms` | Podmínky používání (v1.1 Firebase) |
| `vercel.json` | - | Vercel config (clean URLs + security headers) |

## Hosting

Deploy přes Vercel s GitHub auto-deploy. Custom doména `chytrykosikapp.cz` (Forpsi).
